# content-wellbeing-scanner
A client-side safety and digital wellbeing utility designed to identify adult content triggers and evaluate content filtering mechanisms across public self-improvement communities.

## Purpose
This project is an open-source utility developed to support client-side content blocking (e.g., Android digital wellbeing filters). It interacts with public Reddit metadata to analyze post classifications and compile domain-level safety filters.

## Compliance
- **Read-Only Access:** Does not post, comment, or interact with accounts.
- **Privacy First:** Collects no personal user data or identifiable private information.
- **Responsible Builder Policy:** Adheres strictly to Reddit API rate limits and developer guidelines.
- **Non-Commercial:** Free and open-source project.
